# SKA Project

This folder contains the Next.js application source code and its project files.

## Requirements

- Node.js (LTS recommended)
- npm (included with Node.js)

## Run locally

From this folder, install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production check

```bash
npm run build
npm run start
```

The project uses Next.js, React, and TypeScript. Its main pages and shared components are in `src/`, and static assets are in `public/`.
